# Задача №3 — декоратор `timed_logged`

В файле `timed_logged.py` реализован декоратор, который принимает функцию, запускает её через обёртку с `*arguments` и `**named_arguments`, измеряет время выполнения с помощью `time.perf_counter()`, выводит имя функции, аргументы и результат, а при ошибке записывает её тип и сообщение через `logging` и повторно выбрасывает исключение. `functools.wraps` сохраняет метаданные исходной функции. В файле `main.py` приведён пример использования декоратора и обработки ошибки.

## Запуск

```bash
cd task_3
python main.py
